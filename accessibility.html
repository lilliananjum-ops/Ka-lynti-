KA LYNTI / ACCESSIBILITY

Access that works for more people.

We want this website to be clear, usable and welcoming to disabled people and everyone seeking information.

Accessibility is ongoing work. This page describes the features currently available and invites feedback when something gets in the way.

01 / KEYBOARD

Keyboard navigation

Use Tab to move through links and controls, Shift+Tab to move backward, and Enter or Space to activate controls. A “Skip to main content” link appears when focused.

02 / DISPLAY

Display options

Choose “Display options” in the site header to turn on larger text or high contrast. These preferences are saved in this browser and can be switched off the same way.

03 / MOTION

Reduced motion

The site respects your device’s reduced-motion preference and disables smooth scrolling and decorative transitions where supported.

04 / STRUCTURE

Page structure

Pages use headings, landmarks, labels and visible keyboard focus to support assistive technologies and easier navigation.

Help us improve

We have not claimed formal conformance to an accessibility standard. If you encounter a barrier, please tell us what page and device or assistive technology you were using so we can investigate.
